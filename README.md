# Renewable Energy Explorer

An interactive web GIS application built with **Leaflet, JavaScript, HTML, and CSS** to visualize selected renewable-energy sites in the Washington, DC region.

## Project Overview

The Renewable Energy Explorer demonstrates how web mapping technologies can be used to visualize and explore geographic information through an interactive map.

Users can:

* Explore the map using pan and zoom controls
* View solar and wind energy locations
* Turn Solar and Wind layers on and off
* Click locations to view facility information
* View a map legend and scale bar
* Explore the map using an OpenStreetMap basemap

## Technologies

* **Leaflet.js** — Interactive web mapping
* **JavaScript** — Map functionality and data handling
* **HTML5** — Web page structure
* **CSS3** — Interface and map styling
* **OpenStreetMap** — Basemap

## Data

The current locations are demonstration data created for the purpose of showcasing web-GIS development skills.

Future versions can incorporate publicly available renewable-energy datasets through online APIs or web services.

## Running the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using **Live Server**.
4. Interact with the map in your browser.
